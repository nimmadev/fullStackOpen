# Repository Review App

A mobile application built with React Native and Expo as part of the Full Stack Open course.

The app allows users to browse GitHub repositories, view repository details, and leave reviews.

## Features

- Browse repositories
- Search and sort repositories
- View repository details
- View repository reviews
- Create a review
- Delete your reviews
- User authentication
- GitHub repository links

## Technologies

- React Native
- Expo
- Apollo Client
- GraphQL
- React Router Native
- Formik
- Yup
- date-fns

## Getting Started

Clone the repository:

```bash
git clone https://github.com/nimmadev/fullStackOpen.git
cd fullStackOpen/part10/rate-repository-app
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```

Then open the app using Expo Go or an available emulator.

## Project Structure

src/
